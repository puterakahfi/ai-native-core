# Skills

Skills define repeatable execution procedures for AI agents.

Skills answer:

```text
How should the agent perform the work?
```

Rules are constraints. Skills are procedures.

## Skill Categories

Recommended categories:

```text
skills/
├── product/
├── experience-design/
├── architecture/
├── software-engineering/
├── backend/
├── frontend/
├── database/
├── ai/
├── testing/
├── documentation/
└── review/
```

## Skill File Format

Each skill should include:

1. Skill name
2. Purpose
3. When to use
4. Required input
5. Step-by-step process
6. Output format
7. Quality checklist
8. Failure handling
