# Skill: UI Implementation

## Purpose

Implement UI changes using the approved design direction and component system.

## Procedure

1. Read app config for UI direction, framework, and component system.
2. Reuse shared UI primitives when available.
3. Keep layout readable, responsive, and accessible.
4. Use approved theme and spacing rules.
5. Avoid random decorative elements.
6. Keep UI state clear for empty, loading, error, and success states.

## Native AI Framework Web Direction

```text
Theme: blue clean SaaS
Component system: shadcn/ui-compatible
Layout: dashboard with sidebar
Tone: command center, clear, product-led
```

## Output

Return UI changes and review notes.
