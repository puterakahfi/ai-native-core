# Skill: Test Driven Change

## Purpose

Add or update tests when implementation behavior changes.

## Procedure

1. Identify whether the change affects behavior, UI, configuration parsing, or package boundaries.
2. Add or update tests when a test framework already exists.
3. If no test framework exists, do not introduce one without approval.
4. Provide manual verification steps when automated tests are not available.
5. Report commands needed for verification.

## Output

Return:

```text
Tests Added
Tests Updated
Manual Checks
Commands To Run
Uncovered Risk
```
