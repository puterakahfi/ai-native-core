# Skill: Adapter Handoff Summary

## Purpose

Return a consistent execution summary after a code adapter completes a task.

## Procedure

1. Summarize what was implemented.
2. List files created.
3. List files updated.
4. List dependencies added or changed.
5. List commands the human reviewer should run.
6. Call out risks, incomplete work, and review notes.
7. Check acceptance criteria explicitly.

## Required Output Format

```text
Understanding:
Task Contract Used:
Architecture Decision Applied:
Files Created:
Files Updated:
Dependencies Added:
Commands To Run:
Acceptance Criteria Check:
Risks:
Review Notes:
```
