# Rules

Rules define mandatory constraints for AI-native engineering work.

Rules answer:

```text
What must or must not happen?
```

Rules are not prompts. Rules are guardrails that agents must obey.

## Rule Categories

Recommended categories:

```text
rules/
├── architecture/
├── domain/
├── frontend/
├── backend/
├── testing/
├── security/
├── design/
└── review/
```

## Rule File Format

Each rule should include:

1. Rule name
2. Purpose
3. Applies to
4. Must do
5. Must not do
6. Examples
7. Review checklist
