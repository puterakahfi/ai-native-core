# Docs

This directory stores supporting documentation for the Native AI Framework.

Docs should explain concepts that are reused across products, agents, and workflows.

## Recommended Docs

```text
docs/
├── glossary.md
├── native-ai-lifecycle.md
├── engineering-contract.md
├── memory-vs-knowledge.md
├── evaluation.md
└── tool-governance.md
```

## Documentation Principle

Documentation is the source of truth.

Memory can remember previous decisions, but documentation should store accepted decisions, contracts, rules, skills, and workflows.
