# Workflows

Workflows define repeatable AI-native execution loops.

A workflow should define:

1. Trigger
2. Input source
3. AI processing step
4. Output
5. Destination
6. Human approval point
7. Failure handling
8. Logging
9. Cost consideration
10. Scaling path

## Default Product Development Workflow

```text
Idea
-> Intent
-> Blueprint
-> Experience Design
-> Engineering Contract
-> Knowledge Preparation
-> Rule Selection
-> Skill Selection
-> Agent Planning
-> Execution
-> Test
-> Review
-> Documentation
-> Release
-> Evaluation
-> Memory Update
```

## Default Status System

```text
idea

-> planned
-> generated
-> needs_review
-> approved
-> implemented
-> tested
-> shipped
-> analyzed
-> improved
```
