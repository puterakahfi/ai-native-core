# Templates

Templates provide reusable document structures for the Native AI Framework.

Templates help agents and humans produce consistent artifacts.

## Recommended Templates

```text
templates/
├── intent-template.md
├── product-blueprint-template.md
├── design-brief-template.md
├── mockup-contract-template.md
├── engineering-contract-template.yaml
├── adr-template.md
├── agent-card-template.md
├── rule-template.md
├── skill-template.md
├── feature-spec-template.md
└── evaluation-template.md
```

## Template Principle

Every template should make the output:

- Clear
- Reviewable
- Reusable
- Agent-friendly
- Human-readable
- Productizable
